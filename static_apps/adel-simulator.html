16×2 LCD command & ASCII reference

Commands supported by this simulator's HD44780-style 4-bit interface.

Supported commands (RS = 0)

CommandMeaningSimulator behavior
0x01Clear displayFills both 16-character lines with spaces and returns the write address to line 1, column 1.
0x02Return homeMoves the write address to line 1, column 1 without erasing any characters already stored.
0x04Entry mode: decrementAfter each ASCII character is written, the address moves one position backward. The simulator wraps between the two visible lines.
0x06Entry mode: incrementAfter each ASCII character is written, the address advances one position. This is the normal mode for left-to-right text.
0x08Display offHides the characters without clearing display memory. A later display-on command shows the stored text again.
0x0CDisplay onShows the stored characters. Cursor and blink bits are not visually modeled.
0x80–0x8FSet line 1 address0x80 selects column 1 and 0x8F selects column 16 of the first line.
0xC0–0xCFSet line 2 addressLine 2 uses DDRAM addresses 0x40–0x4F; therefore 0xC0 selects line 2, column 1 and 0xCF selects column 16.

Printable ASCII data (RS = 1)

Send printable ASCII bytes 0x20–0x7E. The character is written at the current LCD address, then the address moves according to the selected entry mode. Each byte still uses two 4-bit transfers: high nibble first, then low nibble.
