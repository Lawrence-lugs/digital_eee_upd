Tutorial

Explore how a cache works

This simulator lets you define a Cache configuration, enter a sequence of memory accesses, then step through how each address maps into the cache and interacts with main memory.

The two main things you control are:

Cache configurationChoose the address width, cache size, block size, associativity, replacement policy, and write policy.
Access seriesEnter the loads and stores that the simulator will process one at a time.
First time learning how cache works?

Turn Tutorial mode On. After each Step, the simulator will guide you through the cache organization, address partitioning, placement, data movement, metadata, and the reason for each hit or miss.

Leave Tutorial mode Off if you just want to use the simulator normally.

Use the highlighted Tutorial mode button in the title banner anytime.
