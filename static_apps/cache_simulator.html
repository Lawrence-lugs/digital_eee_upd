Cache Memory Simulator

Visualize how a memory address is partitioned into tag, set index, and block offset fields, and follow how main-memory blocks are copied into the cache.Designed for EEE 153 (Computer Organization and Embedded Systems I) class.Conceptualized by Adelson Chua

1. Cache configuration

A valid geometry change rebuilds an empty cache while preserving main-memory contents.

2. Access series

The series is parsed live. Editing it restarts the simulation with an empty cache.


            
          

          
Use LB/LH/LW address for loads and SB/SH/SW address value for stores. All addresses must be 4-byte (word) aligned. Multi-byte values use little-endian byte order. Writes use write-back + write-allocate.
